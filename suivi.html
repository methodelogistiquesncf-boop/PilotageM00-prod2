🖥️ Barre du haut & navigation

  • Version (sous le titre) — un clic affiche l’historique des mises à jour (numéro, date, contenu). Les nouvelles versions arrivent automatiquement sur tous les postes : l’application sauvegarde vos saisies en cours puis se recharge toute seule.
  • Date du jour — référence partagée du tableau ; la modifier déclenche une sauvegarde.
  • Statut — « Modifications en cours… » puis « ✓ Sauvegardé » ; « ✓ Synchronisé (temps réel) » quand les données des collègues sont reçues.
  • Onglets — Supermarché, Rassemblement, Actions, Indicateurs (page dédiée), Utilisateurs (administrateurs), Aide.
  • Déconnexion — à droite de la barre.

🛒 Onglet Supermarché

Un tableau par station : Sous-caisse (bleu), Terre-plein (vert), Toiture (jaune). Chaque station liste les engins (libellés modifiables) avec, pour chaque jour (J0 à J-3), le n° d’engin et les sections APPROS / PIÈCES DÉPOSÉES.

  • Dates & jours — cliquer sur une date en tête de colonne pour la modifier ; le libellé J0 / J-1… est éditable.
  • Lignes de remarque — APPROS : champs KIT + SYMBOLE ; PIÈCES DÉPOSÉES : champ KIT uniquement. « + ligne » ajoute, ✕ supprime.
  • Bouton → d’une ligne — envoie cette ligne (KIT / SYMBOLE) vers l’onglet Actions.
  • Points OK / NOK — ronds vert / rouge à gauche du score ; recliquer désactive.
  • Score — champ libre au format 0/0, utilisé pour les taux de réalisation.
  • Bouton → à côté du score — envoie toute la cellule (toutes ses lignes) vers Actions.
  • Boutons J-0 / J-3 — verts et oranges au-dessus des colonnes de dates envoyer les informations pour alimenter les graphiques. .

📦 Onglet Rassemblement

Suivi des articles manquants, groupés par date (« + Ajouter une date »). Chaque ligne : engin, KIT, SYMBOLE, désignation, quantité, commentaire, responsable, reçu.

  • Reçu — cocher grise la ligne et horodate l’arrivée ; « Afficher les reçus » pour les revoir. Une date entièrement reçue est masquée automatiquement.
  • Responsable — saisie libre avec suggestions (rôles, noms des utilisateurs, noms déjà utilisés) ; navigation ↑ / ↓ et Entrée.
  • Largeur des colonnes — tirer la poignée en bord de colonne ; si la place manque, un message invite à réduire d’autres colonnes. Les largeurs sont mémorisées.
  • Statistiques — vue globale, délais, par engin, cadence, top des articles manquants.
  • Exporter CSV / Imprimer cette page — export ou impression de la liste actuelle.

✅ Onglet Actions

Une action est une copie figée de la remarque envoyée depuis le Supermarché (ou créée manuellement via « + Ajouter une action »). Elle survit à la réutilisation de la case d’origine.

  • Champs — engin, poste, section, date, KIT, SYMBOLE, commentaire, responsable, échéance. Les actions envoyées depuis le Supermarché ont KIT / SYMBOLE verrouillés.
  • Échéance dépassée — si l’action n’est pas faite, la ligne est surlignée « En retard ».
  • Fait — coche l’action terminée (grisée / barrée) ; « Afficher les faites » pour les revoir.
  • Filtres — par poste et par section en haut de l’onglet.
  • ✕ Suppression — confirmation obligatoire, opération définitive.
  • Anti-doublon — un second envoi identique non fait ne crée pas de ligne supplémentaire.

📊 Onglet Indicateurs

Deux graphiques mensuels — APPROS et PIÈCES DÉPOSÉES — suivent le taux de réalisation jour par jour.

  • Mois — sélecteur en haut de page pour consulter un autre mois.
  • Courbe J-0 (verte) — taux constaté le jour même ; l’écart entre les deux courbes montre ce qui a évolué entre-temps.
  • Courbe J-3 (orange) — taux consolidé avec un recul de 3 jours.

👥 Onglet Utilisateurs réservé aux Administrateurs

  • Comptes — un utilisateur apparaît après sa première connexion. Prénom / nom éditables ; ils alimentent les suggestions du champ Responsable.
  • + Ajouter un utilisateur — crée le compte sans mot de passe : la personne reçoit un e-mail pour définir le sien.
  • Rôle — menu déroulant ; impossible de supprimer sa propre fiche.
  • 🎭 Gestion des rôles — créer des rôles personnalisés et supprimer n’importe quel rôle (standard ou personnalisé). Si des personnes ont ce rôle, une confirmation le précise : leur rôle est alors effacé et doit être réaffecté. Supprimer « Administrateur » affiche un avertissement spécifique.

💾 Sauvegarde, temps réel & versions

  • Sauvegarde automatique — quelques secondes après chaque modification ; les boutons « Sauvegarder » forcent l’enregistrement immédiat.
  • Double stockage — base Firebase partagée entre tous les utilisateurs + copie de secours locale dans le navigateur.
  • Temps réel — les modifications des collègues arrivent sans recharger la page. Si vous avez des saisies non sauvegardées, elles sont appliquées juste après votre sauvegarde (message « 🔄 Modifs collègues reçues… »).
  • Versions — cliquer sur la version sous le titre pour le détail des mises à jour ; le déploiement est automatique sur tous les postes.
  • Nettoyage automatique — actions faites > 90 jours, historique > 18 mois et rassemblements soldés > 90 jours sont purgés automatiquement.
